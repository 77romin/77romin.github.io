## 프로젝트 개요

HERRAG는 사용자가 MD·TXT·PDF 스토리팩을 선택하거나 업로드하면 그 문서의 인물과 대화하고, 선택에 따라 장면과 결말까지 진행하는 분기형 채팅 게임입니다. AI는 여자 주인공과 장면 묘사를 맡고, 서버는 문서 설정과 게임 진행 규칙을 함께 검증합니다.

레트로 게임기에 팩을 꽂는 경험을 모티브로 기본 스토리팩 5종, 카트리지 보관함, 팩 삽입 애니메이션과 스포일러를 제외한 시작 안내를 구성했습니다.

## 문서 기반 게임 경험

- 기본 5개 팩 또는 최대 2MB의 사용자 문서 업로드
- 문서에서 인물·관계·장면 목표·결말 조건을 추출해 게임 상태로 구성
- 대사와 행동·배경 묘사를 분리해 순차 표시
- 현재 장면 조건을 충족할 때만 다음 장면으로 이동
- 마지막 장면의 조건과 결말 인덱스를 서버가 검증한 뒤 종료
- 동일 콘텐츠의 분석·소개 검수·임베딩 결과를 캐시해 다시 준비하는 시간 절약

## RAG와 근거 판정

문서는 기본 500자, 50자 겹침으로 나누고 Chroma에 `pack_id`와 함께 저장합니다. 매 대화에서는 현재 팩 안에서 Dense 후보 8개와 BM25 후보 8개를 찾고, 가중 RRF로 결합한 상위 4개 청크를 사용합니다. 한국어 조사와 어미 차이는 2·3글자 문자 n-gram으로 보완합니다.

| 판정 | 처리 방식 |
| --- | --- |
| `supported` | 설정에 맞는 말과 자연스러운 일상 대화를 허용 |
| `contradiction` | 명시적 설정 충돌을 캐릭터 말투로 되묻고 근거 원문 표시 |
| `unspecified` | 문서로 확인할 수 없는 구체적 사실임을 안내 |

충돌하거나 확인할 수 없는 발언에서는 장면 진행과 기억 갱신을 막습니다. 모델이 제시한 인용문이 실제 원문에 있는지, 장면 조건과 결말 상태가 유효한지도 서버가 다시 검사합니다.

## 상태 관리와 검증

세션은 충족 조건, 사용자의 원문, 직전 확인 질문과 이미 물어본 질문을 서버 메모리에 보관합니다. 짧은 “응”, “아니요” 같은 답은 직전 질문에만 연결하고, AI의 완료 플래그가 아니라 저장된 조건과 진행 경로를 기준으로 장면을 전환합니다.

실제 AI 호출 없이 세션 교체, 설정 충돌, 조기 결말 차단, 인용 검증, 캐시 재사용과 하이브리드 검색을 확인하는 53개 테스트를 구성했습니다. 별도 평가 흐름에서는 10개 검색 사례를 대상으로 BM25 근거 Recall@3 1.000, MRR 0.883을 기록했습니다.

## 현재 한계

게임 세션은 메모리에 있어 서버 재시작 후 복구되지 않으며, 전역 잠금 때문에 동시 요청이 서로 기다릴 수 있습니다. 응답은 완성된 JSON을 받은 뒤 표시하므로 토큰 스트리밍은 지원하지 않습니다. 검색 지표는 실제 대사의 자연스러움이나 모든 분기의 정확성을 의미하지 않아 별도 플레이 검증이 필요합니다.
