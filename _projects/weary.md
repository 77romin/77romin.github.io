## 제품 개요

!WEARy는 **개인 옷장 관리, 패션 커뮤니티, 패션 중고거래**를 하나의 사용자 흐름으로 연결한 iOS 패션 플랫폼 프로토타입입니다. 옷 사진과 구매 정보를 기록하고 실제 착용 횟수와 1회당 착용 비용을 확인한 뒤, 착장을 공유하거나 활용도가 낮은 옷을 판매할 수 있도록 설계했습니다.

개인 옷장과 비공개 착장은 기기에 보관하고, 사용자가 공개하기로 결정한 게시물·매물·채팅만 서버로 전송하는 로컬 우선 구조를 사용합니다.

## 주요 사용자 경험

- 옷 사진의 배경 제거, 브랜드·카테고리·사이즈·구매일·가격 관리
- 카메라와 사진 보관함을 이용한 착장 기록, 월간 캘린더와 날짜별 착장 조회
- 착용 횟수와 원 단위 1회당 착용 비용 계산
- 실제 착장 중심 피드, 아이템 연결, 좋아요·댓글·북마크·팔로우
- 옷장 데이터를 활용한 판매 글 작성, 관심 등록, 거래 상태와 1:1 채팅
- MapKit 검색과 핀을 이용한 만날 장소 지정

## 온디바이스 착장 후보 추천

Apple Vision 특징값과 인체 포즈 정보를 이용해 촬영한 착장에서 옷장 후보를 추천합니다. 머리·상체·하체·발·가방 위치를 기준으로 카테고리를 보수적으로 선택하고, 사용자가 최종 후보를 확정하는 Human-in-the-loop 방식으로 구성했습니다.

사진과 특징값은 서버로 전송하지 않으며, 추천 실험실에서 처리 시간·캐시·입력 품질을 확인할 수 있습니다. 현재 방식은 범용 의류 탐지 모델이 아닌 가벼운 PoC로, 실제 정확도는 동의받은 별도 데이터셋으로 검증해야 합니다.

## 데이터와 보안 설계

| 데이터 범위 | 저장 위치 | 예시 |
| --- | --- | --- |
| 개인 데이터 | SwiftData | 옷, 구매 정보, 비공개 착장, 착용 통계 |
| 재생성 가능한 데이터 | 로컬 캐시 | 피드와 마켓 조회 결과 |
| 공개 확정 데이터 | Supabase | 프로필, 게시물, 관계, 매물, 채팅, 운영 기록 |

Supabase Auth와 PostgreSQL RLS·RPC·Trigger로 사용자별 접근 권한과 데이터 무결성을 서버에서 집행합니다. 신고·차단, 콘텐츠 숨김, 기간 제한과 정지, 이의 제기와 탈퇴 시 데이터 삭제 흐름도 제품 범위에 포함했습니다.

## 검증과 현재 경계

Swift Testing과 XCTest, Supabase 실서버 통합 테스트로 핵심 동작을 확인합니다. 네트워크가 없어도 개인 옷장과 착장을 사용할 수 있지만, 공개 피드와 거래 기능은 서버 연결이 필요합니다. 소셜 로그인은 진입 UI를 포함하며 공급자별 운영 설정은 별도로 완료해야 합니다.
