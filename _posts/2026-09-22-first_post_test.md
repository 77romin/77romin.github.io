## 개발 블로그를 시작했다

GitHub Pages와 Jekyll Chirpy를 이용해서 개발 블로그를 만들었다.

앞으로 공부하면서 알게 된 내용과 프로젝트 경험을 이곳에 기록할 예정이다.

## 기록할 내용

주로 다음과 같은 내용을 기록하려고 한다.

- Java
- Algorithm
- Web
- iOS
- Projects
- Troubleshooting

## 코드도 작성할 수 있다

Chirpy에서는 Markdown 코드 블록도 지원한다.
